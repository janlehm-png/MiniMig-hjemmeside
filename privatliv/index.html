Privatliv i MiniMigs browserudgave

Senest opdateret: 26. oktober 2026

MiniMig har ingen konto, reklamer, sporing eller analyseværktøjer. Spillets valg sendes ikke til os.

Det gemmes på enheden

Den seneste figur, farver og det valgfrie navn på trøjen gemmes i browserens lokale lagring. Navnet sendes ikke til en server. Spillets filer og billeder gemmes også lokalt, så spillet kan bruges offline.

Sletning og forskellige browsere

Du kan fjerne figuren og offlinefilerne ved at rydde hjemmesidens data i browserens indstillinger. Browseren kan selv rydde data ved pladsmangel. En installeret webapp og forskellige browsere kan have hver sin lagring. At fjerne ikonet fra hjemmeskærmen er ikke nødvendigvis det samme som at slette hjemmesidens data.

Internet og hosting

Første besøg og opdateringer henter spilfiler fra hjemmesiden. Den drives via GitHub Pages, som kan registrere tekniske oplysninger som IP-adresse for at levere siden og beskytte mod misbrug. Se GitHubs privatlivserklæring. Spillet bruger ingen eksterne skrifttyper, statistikværktøjer eller cookies.

Ingen deling eller adgang til Fotos

Browserudgaven har ikke billeddeling, eksport til Fotos eller et galleri. Den beder ikke om adgang til kamera, mikrofon, placering eller billeder.

Kontakt

Skriver du til minimig@lehmann.dk, modtager vi de oplysninger, du selv sender i din e-mail.

Privacy in the browser version

No accounts, ads, analytics or tracking. The latest figure and optional shirt name stay in this browser's local storage. Game files are cached for offline play. Clear this website's data in your browser to remove them; removing the home-screen icon may not clear all data. Separate browsers or an installed web app may use separate storage. GitHub Pages serves the files and may process technical request information such as IP addresses. The game has no photo access or sharing feature. If you email us, we receive the information you include.
